# fujifilm-transfer-app-

Exploring a free app that pushes Fujifilm film simulation recipes straight into a
camera's custom settings slots (target body: **X-S20**, C1–C4).

Start here: **[docs/FEASIBILITY.md](docs/FEASIBILITY.md)** — protocol findings
(PTP over USB, device properties `0xD18C`–`0xD1A5`), prior art, cable-vs-WiFi
analysis, platform/cost comparison, and a suggested build order.
